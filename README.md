# Mohit Karthikeyan: Portfolio

Static site (no build step). Files:
- index.html  the whole site
- photo.jpg   your portrait
- resume.pdf  your resume (the Download buttons point to this file)

## Edit your links
Open index.html, find the CONFIG block near the bottom, and paste your GitHub URL
and project repo links. Empty values are hidden automatically.

## Deploy on Vercel
Option A (fastest, no Git): go to vercel.com/new, drag this whole folder in, click Deploy.
Option B (recommended): push this folder to a GitHub repo, then on vercel.com choose
"Add New > Project", import the repo, leave all settings as they are, and click Deploy.
Every later push to GitHub updates the live site.

Rename the project in Vercel settings (for example "mohit-karthikeyan") to get
a cleaner address: mohit-karthikeyan.vercel.app
